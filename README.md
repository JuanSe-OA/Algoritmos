Análisis de Algoritmia en el Contexto de la Bibliometría
Este proyecto desarrolla una solución integral para explorar y analizar volúmenes de datos derivados de la producción científica en el área del Pensamiento Computacional (Computational Thinking). Utiliza métodos cuantitativos, matemáticos y estadísticos para establecer relaciones e inferencias sobre la información suministrada por bases de datos como ACM, SAGE y ScienceDirect.


Objetivos del Proyecto
Implementar algoritmos de análisis bibliométrico sobre un dominio de conocimiento particular.

Automatizar la cadena de búsqueda y unificación de registros científicos.

Aplicar técnicas de minería de texto y análisis de similitud sobre resúmenes de artículos.


Funcionalidades Principales

Unificación Automática de Datos: Procesamiento de archivos en formatos RIS y BibTex provenientes de diversas fuentes.



Detección de Duplicados: Algoritmo para garantizar la existencia de una sola instancia por producto (artículo, conferencia, capítulo de libro), almacenando los registros repetidos de forma independiente.



Análisis Estadístico: Generación de métricas sobre los 15 autores con mayor productividad, journals, editoriales y tendencias anuales.


Procesamiento de Lenguaje Natural (NLP): * Cálculo de frecuencias de aparición de variables específicas (Habilidades, Conceptos, Actitudes) dentro de los abstracts.


Unificación de términos sinónimos para normalización del análisis.


Visualización Dinámica: Generación interna de nubes de palabras y grafos de co-ocurrencia (co-word network visualization).



Agrupamiento por Similitud: Implementación de técnicas para medir la similitud textual entre abstracts y agrupar artículos relacionados.

Stack Tecnológico
Lenguaje: Python.


Análisis de Datos: Implementaciones de algoritmos de ordenamiento, búsqueda y estructuras de datos para grandes volúmenes de información.



Arquitectura: Diseño basado en requerimientos funcionales y despliegue documentado.
